## Overview

RunAndGun adds movement-while-shooting capability to RimWorld's turn-based combat, allowing colonists and enemies to fire ranged weapons while running with configurable accuracy penalties that scale with movement speed and weapon type. This fundamentally changes combat tactics, enabling mobile fire-and-maneuver tactics rather than static firing lines.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld RunAndGun** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Move and Shoot** | Pawns can fire ranged weapons while moving at configurable accuracy cost |
| **Accuracy Penalty** | Configurable per-weapon-class accuracy reduction for firing while moving |
| **Enemy Compat** | Raider and mechanoid AI also benefits from move-while-shooting capability |
| **Speed Scaling** | Accuracy penalty scales with actual movement speed of the shooting pawn |
